# FSCAN 内网扫描台 · 使用说明

一个给 [fscan](https://github.com/shadow1ng/fscan) 套的可视化控制台：左侧填参数，中间看实时输出和结果，右侧看扫描态势。所有扫描都在本机执行，不联网上传任何数据。

- 作者：**四月** · [github.com/mcsiyue](https://github.com/mcsiyue)
- 项目主页：[github.com/mcsiyue/fscan-console](https://github.com/mcsiyue/fscan-console)
- 基于：[shadow1ng/fscan](https://github.com/shadow1ng/fscan) v2.2.2（MIT）
- 内置 fscan 版本：**v2.2.2**
- 界面：本地网页 + 独立应用窗口（Edge / Chrome）
- 数据：`%LOCALAPPDATA%\FScanDesk`

## 快速开始

1. 双击桌面上的 **fscan 可视化控制台**。
2. 在「目标」里填一个地址，例如 `192.168.1.0/24`，或者点「导入目标文件」。
   - 支持 IP、CIDR、域名，一行一个；
   - 如果填的是 `http://` / `https://` 开头的完整 URL，会走 fscan 的 Web 扫描（一次只能填一个 URL）。
3. 选端口组（常用 / Web / 数据库 / 全端口 / 自定义）。
4. 点 **开始扫描**，或按 `Ctrl + Enter`。
5. 扫描中可以在下面看实时输出；结果会一条条进入「扫描结果」表格。
6. 扫描结束会自动归档到「历史记录」，可以随时查看、导出 CSV / JSON、打开数据目录。

第一次打开会弹出一个独立窗口；如果没弹出来，用浏览器访问程序给出的本地地址即可。

## 界面说明

| 区域 | 作用 |
| --- | --- |
| 顶部状态 | 待命 / 扫描中 / 已完成 / 已停止 / 出错，以及本次耗时 |
| 左侧配置 | 目标、排除、端口组、扫描模式、爆破/POC 开关、并发、认证字典、代理、附加参数 |
| 中间控制台 | fscan 的原始输出实时滚动，可暂停自动滚动、清空、导出日志 |
| 中间结果表 | 主机 / 端口 / 服务 / 风险四个维度，点任意一行展开完整字段与 RAW JSON |
| 右侧雷达 | 发现主机数、主机分布、Web / 风险标记；下面是主机与风险列表 |
| 历史记录 | 每次扫描的配置、统计、控制台日志与结果，全部保存在本机 |

### 常用操作

- **快速侦察**：常用端口、关闭爆破和 POC，适合先摸清资产。
- **深度扫描**：全插件默认参数，速度慢但覆盖全。
- **仅存活**：只做 ICMP 探活，不扫端口。
- **指定插件**：在「扫描模式」里选「指定插件」，填例如 `ssh,smb,rdp`。
- **自定义端口**：支持逗号、区间，例如 `80,443,8000-8100`。
- **附加参数**：在「高级」里原样追加到 fscan 命令行，适合用界面没暴露的参数。
- **查看历史结果**：在「历史记录」里点任意任务会打开只读弹层，不会打断正在运行的扫描；关闭后当前任务和结果都还在。扫描进行中时，历史页顶部会出现「扫描进行中 · 回到扫描台」按钮。

## 数据与导出

- 数据目录：`%LOCALAPPDATA%\FScanDesk`
  - `scans\<任务ID>\`：`meta.json`、`result.json`、`console.log`、`command.txt`
  - `bin\fscan.exe`：从程序里复制出来的 fscan，可自行替换升级
  - `settings.json`：fscan 路径、界面打开方式、上次配置
- 导出：结果表右上角的两个图标分别导出 **CSV** 和 **JSON**；历史卡片上也有同样的按钮。
- 关闭窗口后，后台进程会在约 3 分钟无操作后自动退出；正在扫描时不会退出。
- 需要彻底退出：设置 → **退出程序**。

## 升级 fscan

把新的 `fscan.exe` 放到程序目录的 `tools\` 下（或直接替换 `%LOCALAPPDATA%\FScanDesk\bin\fscan.exe`），
然后在「设置」里点「自动检测」或填入路径保存即可。界面会显示检测到的版本与插件数量。

程序启动时优先使用：

1. 用户在设置里指定的路径；
2. 程序目录下的 `tools\fscan.exe`；
3. 内置在 exe 里的 fscan（首次运行会复制到 `%LOCALAPPDATA%\FScanDesk\bin\`）。

## 常见问题

**双击没反应？**
看看任务管理器里有没有 `fscan可视化控制台.exe`；也可以直接运行程序目录里的 exe，或在设置里切换「界面打开方式」。

**Windows 提示未知发布者 / 杀软报警？**
程序是本地打包的 Python 单文件 exe，没有代码签名；fscan 本身也常被杀软标记。把程序目录加入信任即可。

**端口被占用？**
程序默认从 `47321` 开始找空闲端口，一般不会冲突。若本地已有同名实例，会直接复用它的窗口。

**扫描失败说「初始化失败 / Access is denied」？**
fscan 需要把结果写到本机数据目录。确保 `%LOCALAPPDATA%\FScanDesk` 可写，或把程序放到普通目录再试。

**结果为空？**
确认目标可达、端口组覆盖到了开放端口；可以先用「仅存活」确认主机在线，再用「常用」端口扫。
